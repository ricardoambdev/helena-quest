| paper | `#FAF8F5` | Fundo claro (answer, audio) |

| rule | `#E0DCD3` | Bordas de cards |
| Inter | display | Títulos grandes (result) |
| Nunito | body | Textos corridos |
| JetBrains Mono | labels, buttons, numbers | Todos os botões, display numérico, badges |
| BorderRadius | 12px | Cards, botões, inputs |
| Botões | ignite bg, white text | ElevatedButton em todas as telas |

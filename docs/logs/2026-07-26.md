## Decisões Técnicas

| Decisão | Alternativa | Motivo |
|---------|------------|--------|
| layout `layouts.app` vs nenhum | `component_layout`: null dava MissingLayoutException | Livewire 4 exige layout string; criado minimal shell |
| wire:poll + wire:ignore vs $wire.get puro | Polling para ranking/progresso, $wire.get para fotos/áudio | Polling preserva ranking com Livewire, Alpine gerencia estado de carrossel/áudio |
| Alpine busca dados via $wire.get() | @js($this->...) no Alpine x-data | Evita re-render de Alpine no poll — dados sincronizados via livewire:updated |
| Echo CDN vs apenas polling | CDN (3 scripts) é fallback para quando Reverb não estiver disponível | wire:poll.5s funciona sempre; Echo entra como enhancement |
